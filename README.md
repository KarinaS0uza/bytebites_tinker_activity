# ByteBites

A Mermaid class diagram for the Python backend of a campus food ordering app, saved in `bytebites_design.mmd`.

## Classes

- **Customer:** Stores a customer's name and purchase history.
- **MenuItem:** Stores an item's name, price, category, and popularity rating.
- **Menu:** Manages menu items and filters them by category.
- **Order:** Groups selected items and calculates the total cost.
